# Pump source asset

Original: Innerscene, “Centrifugal pump with electric motor”.
https://www.innerscene.com/tools/library/3d-parts/centrifugal-pump-with-electric-motor-486d9de9
Downloaded 2026-10-31. Source filename: centrifugal-pump-with-electric-motor.step.

The publisher explicitly dedicates this original unbranded model to CC0:
https://creativecommons.org/publicdomain/zero/1.0/
“Public domain (CC0). Free to use, modify and redistribute for any purpose, including commercially, with no credit required.”

The conversion script downloads the original STEP when missing. scripts/convert-pump.py extracts solids 9 (volute casing), 10 (front cover), and 37 (impeller), tessellates them, changes axes, and scales them for gameplay. Generated mesh data is src/pump-meshes.json. The source assembly has 98 solids. Other level components and the crew are original procedural game assets, not part of the downloaded model. The playable level is an exaggerated adaptation, not an engineering simulation.
